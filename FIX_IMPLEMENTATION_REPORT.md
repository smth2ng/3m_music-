# Исправления по итогам аудита 3М MUSIC

Работы выполнены 23 ноября 2026 года в рабочем дереве после исходного аудита коммита 7d8c0d3. Исходный аудит сохранён в пяти отдельных отчётах. Этот файл описывает последующие изменения и фактические повторные проверки.

Коммитов, push и деплоя в ходе исправлений не выполнялось. Данные тестовых профилей изолированы от пользовательского браузера. Реальных записей в GitHub через админку тесты не делали.

## Публикация общего контента

Технически подключён единый серверный GitHub-процесс для артистов, преподавателей и релизов. После успешного серверного входа сохранение переводит data URI фотографий в файлы assets/uploads, записывает JSON и обновляет main без force. Существующий GitHub Actions публикует сборку. Само сохранение и публикация сайта являются разными операциями.

На отдельном Node.js-хостинге нужны ADMIN_PASSWORD, ADMIN_GITHUB_TOKEN с Contents Read and write для этого репозитория и ADMIN_ORIGIN с точным HTTPS-origin. Когда все настройки присутствуют, сервер отдаёт конфигурацию настоящего входа. Токен остаётся на сервере. Превью загруженных файлов доступно через защищённый endpoint. Ссылка «На сайт» в серверной админке ведёт на текущий GitHub Pages.

На GitHub Pages сохранён ранее запрошенный деморежим с паролем 6767. В нём данные остаются в браузере. Пароль виден в клиентском коде. Эту временную архитектуру нельзя сделать защищённой серверной авторизацией без фактического серверного размещения.

Чтобы перенести демоданные из текущего браузера, можно скачать копию и восстановить выбранные разделы уже в настроенной серверной админке. Перенос не выполняется автоматически между разными origin.

## Наполнение и известные ограничения

| Пункт исходного аудита | Текущий статус |
| --- | --- |
| LIMIT-01, общее хранение | Серверный механизм реализован и проверен на mock API. Реальная публикация требует внешнего размещения и секретов. На текущем GitHub Pages остаётся демо |
| LIMIT-02, пароль в JavaScript | Сохранён для временного демо по прежнему запросу. Настроенный Node.js использует серверный пароль и сессию |
| LIMIT-03, пустые профили | Пустые экраны устранены. Есть H1, фото, навигация и сообщение о подготовке информации. Реальные названия и биографии не выдумывались |
| LIMIT-04, содержимое преподавателей | Есть явное сообщение при отсутствии описания. Для Полины по-прежнему нужна настоящая фотография, для обоих — фактические описания |
| LIMIT-05, внешние проверки | Продакшен, Яндекс Карты и дополнительные браузеры остаются ограничены сетью среды |

Robots.txt расположен в подпапке проекта. Управление robots.txt всего домена smth2ng.github.io требует доступа к корню домена. Для служебных HTML действует собственный meta noindex. Реальное исключение из поискового индекса не проверялось.

## Что требует внешних данных или доступа

- Node.js-хостинг и серверные секреты для общей публикации.
- Реальные названия и материалы исходных артистов, фотография Полины и описания преподавателей.
- Доступный production URL, карта и браузеры Firefox/WebKit для заключительной проверки.
- Полевые Web Vitals и проверка реальными скринридерами.
