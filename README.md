# 3М music

Адаптивный сайт продюсерского центра 3М music. HTML, CSS и JavaScript без клиентских библиотек; фотографии и векторные логотипы извлечены из макетов и хранятся локально.

## Запуск

Нужен Node.js 20 или новее.

```sh
npm ci
npm run dev
```

Сервер слушает порт 3000; другой порт задаётся переменной `PORT`. Рабочий каталог — корень репозитория.

```sh
npm run build
SERVE_DIST=1 npm start
```

Сборка создаёт `dist/`, который можно разместить на любом хостинге статических сайтов.

## Поведение

- Карточки артистов переключаются горизонтальной прокруткой над карточкой, клавишами ←/→ или горизонтальным свайпом. Вертикальная прокрутка листает страницу и не переключает артистов. Нажатие открывает отдельную страницу артиста в новой вкладке; страницы `public/artists/artist-1.html` и `artist-2.html` пока пустые. Фоновая карточка затемняется оверлеем 38%; переходы учитывают `prefers-reduced-motion`.
- Из верхнего меню можно перейти на главную и прямо к артистам, преподавателям, контактам и услугам. На главной находится краткое описание услуг, на странице «О студии» — подробности, этапы работы и преподаватели.
- «Оставить заявку» открывает контактное окно с телефоном Михаила. Серверная отправка заявки не подключена: в исходных материалах нет формы или адреса обработчика.
- Ссылка в контактах открывает адрес центра в Яндекс Картах.
- Текст остаётся доступным для поиска и выделения; сайт не использует изображение макета вместо HTML. В SVG текст переведён в кривые; для текстовой верстки используется Arial с системными заменами.

## Проверки

```sh
npm test
```

Тесты Playwright запускают свой сервер на порту 4173 и проверяют загрузку изображений и отсутствие горизонтальной прокрутки на 7 ширинах от 320 до 1920 px. На 390 и 1440 px дополнительно проверяются расположение основных блоков, меню, навигация, карусель, контактное окно и анимация прокрутки. На 390 px также проверяется сенсорный свайп.

Если Chromium не установлен в системе, выполните `npx playwright install chromium`. Можно задать `CHROMIUM_PATH` для своего исполняемого файла браузера.

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает и публикует `dist/` при каждом push в `main`. В настройках репозитория Pages → Source должно быть выбрано GitHub Actions.

Публичный адрес: https://smth2ng.github.io/3m_music-/

Относительные пути к ресурсам позволяют запускать сайт как в корне домена, так и в каталоге репозитория на GitHub Pages.

## Анимация прокрутки

Секции главной страницы появляются с плавным смещением, масштабом и расфокусировкой; карточки внутри — с небольшой последовательной задержкой. Полупрозрачные панели используют backdrop blur и светлую стеклянную кромку. Между секциями увеличены отступы.

CSS scroll snap в режиме proximity мягко притягивает вид к ближайшей секции, сохраняя возможность читать длинные блоки. Горизонтальная карусель артистов работает независимо. При включённом системном уменьшении движения анимации и притяжение отключены; без JavaScript содержимое остаётся видимым.
