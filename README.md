# 3М music

Адаптивный сайт продюсерского центра 3М music. HTML, CSS и JavaScript без клиентских библиотек; фотографии и векторные логотипы извлечены из макетов и хранятся локально.

## Запуск

Нужен Node.js 20 или новее.

```sh
npm ci
npm run dev
```

Сервер слушает порт 3000; другой порт задаётся переменной `PORT`. Рабочий каталог — корень репозитория.

```sh
npm run build
SERVE_DIST=1 npm start
```

Сборка создаёт `dist/`, который можно разместить на любом хостинге статических сайтов.

## Поведение

- Карточки артистов переключаются горизонтальной прокруткой над карточкой, клавишами ←/→ или горизонтальным свайпом. Вертикальная прокрутка листает страницу и не переключает артистов. Нажатие открывает отдельную страницу артиста в новой вкладке; страницы `public/artists/artist-1.html` и `artist-2.html` пока пустые. Фоновая карточка затемняется оверлеем 38%; переходы учитывают `prefers-reduced-motion`.
- Из верхнего меню можно перейти на главную и прямо к артистам, преподавателям, контактам. Артисты, преподаватели и контакты открываются на отдельных страницах. Услуги и этапы работы размещены на главной.
- «Оставить заявку» открывает контактное окно с телефоном Михаила. Серверная отправка заявки не подключена: в исходных материалах нет формы или адреса обработчика.
- Ссылка в контактах открывает адрес центра в Яндекс Картах.
- Текст остаётся доступным для поиска и выделения; сайт не использует изображение макета вместо HTML. В SVG текст переведён в кривые; для текстовой верстки используется Arial с системными заменами.

## Проверки

```sh
npm test
```

Тесты Playwright запускают свой сервер на порту 4173 и проверяют загрузку изображений и отсутствие горизонтальной прокрутки на 7 ширинах от 320 до 1920 px. На 390 и 1440 px дополнительно проверяются расположение основных блоков, меню, навигация, карусель, контактное окно и анимация прокрутки. На 390 px также проверяется сенсорный свайп.

Если Chromium не установлен в системе, выполните `npx playwright install chromium`. Можно задать `CHROMIUM_PATH` для своего исполняемого файла браузера.

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает и публикует `dist/` при каждом push в `main`. В настройках репозитория Pages → Source должно быть выбрано GitHub Actions.

Публичный адрес: https://smth2ng.github.io/3m_music-/

Относительные пути к ресурсам позволяют запускать сайт как в корне домена, так и в каталоге репозитория на GitHub Pages.

## Анимация прокрутки

Секции главной страницы появляются с плавным смещением, масштабом и расфокусировкой; карточки внутри — с небольшой последовательной задержкой. Полупрозрачные панели используют backdrop blur и светлую стеклянную кромку. Между секциями увеличены отступы.

CSS scroll snap в режиме proximity мягко притягивает вид к ближайшей секции, сохраняя возможность читать длинные блоки. Горизонтальная карусель артистов работает независимо. При включённом системном уменьшении движения анимации и притяжение отключены; без JavaScript содержимое остаётся видимым.

## Управление артистами

Админка находится по адресу `/admin/` на Node.js-сервере. Для запуска задайте через секреты хостинга:
- `ADMIN_PASSWORD` — длинный уникальный пароль администратора.
- `ADMIN_GITHUB_TOKEN` — fine-grained GitHub token с доступом только к `smth2ng/3m_music-` и разрешением Contents — Read and write.
- `ADMIN_ORIGIN` — точный публичный origin сервера с HTTPS без завершающего слеша, например `https://admin.example.com`.

Команды хостинга — установка `npm ci`, сборка `npm run build`, запуск `SERVE_DIST=1 npm start`. Используйте Node.js 20+ и одну реплику сервера. Сессии живут в памяти до 8 часов, после перезапуска требуется повторный вход. Хостинг должен передавать браузерный заголовок Origin без изменений.

Для локального запуска используйте `ADMIN_ORIGIN=http://localhost:3000` и задайте остальные секреты через окружение. Пароль и токен не записывайте в репозиторий. В браузер отправляется только защищённая HttpOnly cookie с идентификатором сессии. Запись в GitHub выполняет сервер. Рабочий токен с правом записи всё равно требуется.

GitHub Pages продолжает публиковать публичный сайт. Админку нужно открывать на отдельном Node.js-хостинге: GitHub Pages не выполняет серверную проверку пароля.

Добавьте название, главное фото и при необходимости описание, логотип, дополнительные фотографии, HTTPS-ссылку на видео и платформы прослушивания. Поддерживаются PNG, JPEG и WebP до 8 МБ на файл. Ссылки на платформы вводятся по одной в строке в формате `Название | https://адрес`. При редактировании снимите флажок у фотографии, чтобы убрать её из галереи. Удаление артиста требует подтверждения.

Сохранение создаёт один коммит в main с данными и фотографиями. Публичный сайт обновляется после успешного workflow GitHub Pages. При конфликте параллельных изменений войдите снова и повторите правку на актуальных данных. Файлы старых фотографий остаются в репозитории, но удалённые артисты и фотографии исчезают со страниц после сборки.

Данные находятся в `public/data/artists.json`. Команда `npm run build` создаёт страницы артистов и добавляет их в карусели главной и страницы артистов. Для локальной проверки используйте `npm run build`, затем `SERVE_DIST=1 npm start`. Две исходные карточки сохраняются.

### Преподаватели в деморежиме

После входа в админку раздел «Преподаватели» позволяет добавлять, удалять с подтверждением и редактировать преподавателей, включая существующие карточки Михаила Гришина и Полины Гевель: имя, описание, замену или удаление фото. Изменения сохраняются отдельно от артистов в текущем браузере и сразу подхватываются страницей преподавателей, включая открытую в другой вкладке. Серверная публикация преподавателей пока не подключена.
