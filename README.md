# 3М music

Адаптивный сайт продюсерского центра по предоставленным SVG-макетам 1440 и 390 px. HTML, CSS и JavaScript без клиентских библиотек; фотографии и векторные логотипы извлечены из макетов и хранятся локально.

## Запуск

Нужен Node.js 20 или новее.

```sh
npm ci
npm run dev
```

Сервер слушает порт 3000; другой порт задаётся переменной `PORT`. Рабочий каталог — корень репозитория.

```sh
npm run build
SERVE_DIST=1 npm start
```

Сборка создаёт `dist/`, который можно разместить на любом хостинге статических сайтов.

## Поведение

- Карточки артистов переключаются нажатием, клавишами ←/→ или горизонтальным свайпом. Фоновая карточка затемняется оверлеем 38%; переходы учитывают `prefers-reduced-motion`.
- Меню закрывается после выбора раздела, по Escape и нажатию вне меню; доступно с клавиатуры.
- «Оставить заявку» открывает контактное окно с телефоном Михаила. Серверная отправка заявки не подключена: в исходных материалах нет формы или адреса обработчика.
- Карта повторяет заглушку из макета и открывает поиск указанного адреса в Яндекс Картах. Фотография Полины в исходных материалах отсутствует; её карточка сохранена как в макете.
- Текст остаётся доступным для поиска и выделения; сайт не использует изображение макета вместо HTML. В SVG текст переведён в кривые; для текстовой верстки используется Arial с системными заменами.

## Проверки

```sh
npm test
```

Тесты Playwright запускают свой сервер на порту 4173 и проверяют 7 ширин от 320 до 1920 px: загрузку изображений, отсутствие горизонтальной прокрутки, меню, навигацию, карусель, затемнение, настоящий touch-свайп и контактное окно. Для 390 и 1440 px проверяются координаты основных блоков и сохраняются скриншоты в `test-results/`.

Если Chromium не установлен в системе, выполните `npx playwright install chromium`. Можно задать `CHROMIUM_PATH` для своего исполняемого файла браузера.

## GitHub Pages

Workflow `.github/workflows/pages.yml` собирает и публикует `dist/` при каждом push в `main`. В настройках репозитория Pages → Source должно быть выбрано GitHub Actions.

Публичный адрес: https://smth2ng.github.io/3m_music-/

Относительные пути к ресурсам позволяют запускать сайт как в корне домена, так и в каталоге репозитория на GitHub Pages.
